# Processing-data-using-NumPy


## Цель
Освоение методов векторизованной обработки числовых данных, работы со структурированными массивами, оптимизации операций группировки и анализа временных рядов на базе библиотеки `NumPy`.

###  1. Загрузка и подготовка данных
- Прочитать CSV-файл через `numpy.genfromtxt` или построчный парсер + `numpy.array`.
- Создать структурированный массив с явным указанием `dtype`.
- Определить количество строк и объём занимаемой памяти (в байтах и МБ).
- Подсчитать количество `NaN` и `Inf` в числовых полях. Вывести предупреждение, если их доля `> 3%`.
- Сохранить подготовленный массив.

 **Ожидаемый результат:** Файл с очищенным структурированным массивом + лог с информацией о памяти и пропусках.

---

### 2. Векторизованная фильтрация и очистка
- Найти строки с аномалиями, вывести их количество и долю от общего набора.
- Выполнить очистку данных и обрезать выбросы.
 **Ограничение:** Запрещены циклы `for` по строкам. Разрешены только булевы маски, `np.where`, `np.clip`.

 **Ожидаемый результат:** Массив без аномальных выбросов, статистика удалённых/изменённых строк.

---

###  3. Группировка и Z-score нормализация
- Выполнить группировку по заданному полю через `np.unique` + цикл по уникальным группам.
- Определить количество групп и мощность каждой группы (число строк).
- Рассчитать среднее значение и среднее отклонение по указанной характеристике в каждой группе.
- Выполнить Z-score нормализацию заданной характеристики внутри групп (среднее `0`, стандартное отклонение `1`).
- Сохранить нормализованный массив.
 **Ограничение:** Запрещены поэлементные циклы по строкам исходного массива.

 **Ожидаемый результат:** Нормализованный массив, сохранённый на диск, таблица со статистиками по группам.

---

###  4. Скользящее окно и разностные признаки
- Реализовать скользящее среднее для заданной характеристики с окном `k` через кумулятивную сумму (сложность `O(N)`, без циклов). Обрезать первые `k-1` значений или дополнить `np.pad`.
- Вычислить скорость изменения характеристики между соседними записями (`np.diff`).
- Создать новый признак на основе `diff` и добавить его в массив как новое поле.

 **Ожидаемый результат:** Массив с новыми колонками: скользящее среднее и скорость изменения.

---

### 5. Создание производных признаков (Feature Engineering)
- Рассчитать 1–2 новых показателя на основе существующих полей, логически связанных с предметной областью.
- Использовать безопасные вычисления: при делении применять `np.where` или добавлять `1e-8` к знаменателю.
- Заменить возникшие `Inf`/`-Inf`/`NaN` в новых полях на нейтральные значения (`0` или медиану столбца).

 **Ожидаемый результат:** Массив с корректно рассчитанными производными признаками без артефактов деления.

---

### 6. Условная агрегация по группам
- Сформировать составную булевую маску без циклов для фильтрации записей по дополнительному условию.
- Для каждой группы рассчитать статистики (среднее, медиану, 90-й процентиль) только по отфильтрованному подмножеству.
- Сформировать таблицу/массив формы `(N_groups, 3)` вида `[group_id, mean_conditional, median_conditional]`.

 **Ожидаемый результат:** Агрегированная таблица условных статистик по группам.

---

### 7. Лаговые признаки и анализ временных сдвигов
- Создать признак «предыдущее значение» (`lag=1`) через `np.roll` или срез `[1:]`.
- Вычислить разницу между текущим и лаговым значением.
- Обработать граничные элементы. Найти долю записей, где значение выросло/упало.
- Вывести распределение знаков разницы (рост, падение, неизменность) через `np.sign` и `np.bincount`/`np.unique`.

 **Ожидаемый результат:** Массив с лаговым признаком, статистика направлений изменений.

---

### 8. Групповая робастная замена выбросов (IQR)
- Внутри каждой группы найти `Q1` и `Q3`, вычислить `IQR` и границы: `[Q1 - 1.5·IQR, Q3 + 1.5·IQR]`.
- Заменить выбросы, выходящие за границы, на медиану соответствующей группы.
- Вывести количество заменённых значений по каждой группе и общую долю изменённых записей.

 **Ожидаемый результат:** Очищенный массив, отчёт по заменам IQR-методом.

---

### 9. Проверка согласованности и логической целостности
- Сформировать составную булевую маску для поиска строк, нарушающих предметно-ориентированные правила.
- Вывести абсолютное количество и долю нарушений.
- Заменить некорректные флаги/статусы на эталонные значения с помощью `np.where`.

 **Ожидаемый результат:** Лог нарушений, корректно исправленный массив.

---

### 10. Частотный анализ и сжатие редких категорий
- Проанализировать распределение категориального поля.
- Найти категории, встречающиеся менее чем в `1%` записей.
- Объединить их в единую категорию `OTHER` (присвоить код `0` или `255`).

 **Ожидаемый результат:** Массив с оптимизированным категориальным полем, распределение до/после.
